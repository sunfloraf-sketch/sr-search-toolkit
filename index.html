SR 檢索工具組Systematic Review Search Toolkit

系統性文獻回顧檢索的三個獨立小工具，各自可單獨使用，也能互相搭配。每個頁面都能跳到另外兩個。Three independent tools for systematic-review searching. Use any one on its own, or combine them — every page links to the other two.

三個工具沒有先後順序，依你的需要挑選：整理同義詞的鄰近字片段、建立含控制詞彙的 PICO 檢索策略、或把檢索式在各資料庫間轉換。 The three tools are not sequential — pick whichever you need: build proximity fragments from synonyms, assemble a PICO strategy with controlled vocabulary, or convert a query between databases.

鄰近字組合器Proximity Builder

Proximity Builder

把多堆同義詞組成鄰近字（adj/near/N）片段；也能貼一份 Before 清單自動分堆，整理好可直接送進語法轉換器。Turn stacks of synonyms into a proximity (adj/near/N) fragment, or auto-split a Before list into stacks — then send it straight to the converter.

PICO 檢索策略產生器PICO Strategy Builder

PICO Strategy Builder

在 PICO 概念表填入自由詞與控制詞彙，選欄位完整度，一鍵生成各資料庫「帶行號」的檢索策略（內建 MeSH／Emtree／CINAHL Headings 對應）。Fill in free-text and controlled terms per PICO concept, pick a field level, and generate line-numbered strategies for each database (with MeSH / Emtree / CINAHL Headings mapping built in).

開啟工具 →Open tool →

資料庫檢索語法轉換器Search Syntax Converter

Search Syntax Converter

貼上任一起始資料庫的檢索式，一鍵轉出 7 大資料庫／平台的語法，可用 #1 #2 引用行號，並可下載 Word。Paste a query written for any starting database and generate syntax for 7 databases/platforms in one click — reference lines with #1 #2, and export to Word.

開啟工具 →Open tool →
