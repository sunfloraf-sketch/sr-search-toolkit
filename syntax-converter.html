重要注意事項（來自原始對照表） Important notes (from the source reference table)
[註1] EBSCOhost 介面：僅 CINAHL 與 MEDLINE 可用 MH ("pain+") 含下位詞；其他資料庫(Academic Search Complete, PsycInfo, ERIC…)須以控制詞彙工具逐層 Explode & Add。
[註2] 控制詞彙為單字時雙引號可省；片語在 Embase / Cochrane、或詞彙本身含 and/or 時，雙引號必須。
[註3] 兩字以上詞彙(如 physical activity)務必自行指定關係(交集 / 鄰近 / 片語)，否則各庫預設邏輯不一：PubMed 交集與片語並用；Ovid 片語；Embase / Scopus 交集(且可能誤拆)；EBSCO / Cochrane / WoS 交集。希望片語檢索時務必加雙引號。
[Note 1] EBSCOhost: only CINAHL & MEDLINE support MH ("pain+") to include narrower terms; other databases require manual Explode & Add via the thesaurus.
[Note 2] Quotes are optional for single-word controlled terms; for phrases in Embase / Cochrane, or terms containing and/or, quotes are required.
[Note 3] For multi-word concepts, always specify the relationship (intersection / proximity / phrase) yourself — database defaults differ and will otherwise produce inconsistent searches.
